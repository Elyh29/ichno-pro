# Installation

1. **Disable the free Ichno** if it is installed: only one edition can be active at a time (Ichno PRO refuses to start next to it).
2. Blender ‣ Edit ‣ Preferences ‣ Add-ons ‣ ⌄ ‣ **Install from Disk**, then pick the `ichno_pro-x.y.z.zip` file from Gumroad.
3. The **Ichno** tab appears in the 3D Viewport sidebar (N), with the PRO panels.

Blender 4.3 or newer (tested up to 5.2). Windows, macOS and Linux.

**Updating:** download the new zip from your Gumroad library and install it the same way; no need to restart Blender.
Your settings are stored in the .blend files and are kept.

**Your first drawing:** see [Installation in the Ichno wiki](https://github.com/Elyh29/ichno/wiki/Installation#your-first-drawing).
