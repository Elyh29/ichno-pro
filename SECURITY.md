# Security policy

## Supported versions
Only the latest version of Ichno PRO receives fixes. Download it again from your Gumroad library to update.

## Reporting a vulnerability
Please do **not** open a public issue. Use GitHub's private reporting instead:
**Security ‣ Report a vulnerability** on this repository.

You will get an answer within 7 days. Ichno PRO runs locally, makes no network connection and only writes files
in the output folder you choose.
